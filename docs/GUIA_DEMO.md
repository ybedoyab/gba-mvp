# Guía para presentar el MVP

## Arranque

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`. Entra con el correo ya escrito. La contraseña no se valida.

Para volver al estado inicial: menú de Laura Gómez → Reiniciar demo.

## Guion de 90 segundos

Activa **Modo presentación** en el menú de Laura si quieres la cinta inferior con las escenas. No hace clics sola.

1. **0:00 Login.** Muestra el fondo oscuro, el logotipo y los aliados. Di que el sector no se transforma por frentes aislados.
2. **0:08 Dashboard.** Inicia sesión. Señala Cooperativa Ejemplo y los cuatro indicadores: formación, planeación, ejecución y pendientes.
3. **0:30 Oferta y ejes.** Recorre las tarjetas y abre Formación, Planeación y Ejecución en el menú oscuro. El menú claro lista las secciones.
4. **0:40 Planeación.** Entra a Mi Transformación. Abre preoperativos y el Programa TD. Si hace falta, entra al módulo 3, que está en curso.
5. **0:52 Academy.** Muestra la ruta SARLAFT y abre la lección «Gestión del riesgo en decisiones reales».
6. **1:07 Reportería.** Cambia «Ver como» de participante a jefatura. Los gráficos y la tabla cambian de escala.
7. **1:18 Cierre.** Vuelve al dashboard. RedCoop conecta estrategia, capacidades y acción.

## Gestos útiles si hay preguntas

- Cargar el acuerdo de datos en Preoperativos: el pendiente y el índice se actualizan.
- Marcar la lección como completada: Academy y la ruta suben. El proyecto no queda acreditado.
- En Proyectos, marcar evidencias y enviar a validación. El estado pasa a revisión experta.
- Cambiar la entidad a Aurora: otro expediente, otro avance, sin mezclar las cifras de Ejemplo.
- Abrir GIO desde el índice o desde la lección: la respuesta cambia de contexto.

## Límites que conviene decir en voz alta

No hay autenticación segura, ni aislamiento productivo, ni integraciones verificadas. Los logos de RedCoop son referencia visual y requieren validación de marca.
